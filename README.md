# App de Lista de Tarefas (Android Nativo)

Projeto desenvolvido como parte dos meus estudos em Engenharia de Computação . O aplicativo é uma ferramenta de gerenciamento de tarefas (To-Do List) focado em aplicar conceitos de desenvolvimento mobile nativo e automação de testes.

## 🚀 Funcionalidades
* Adição de tarefas em tempo real.
* Interface intuitiva utilizando XML Layouts.
* Gerenciamento de ciclo de vida da Activity.

## 🛠 Tecnologias e Ferramentas
* **Linguagem:** Java
* **Plataforma:** Android SDK
* **IDE:** Android Studio
* **Testes:** Espresso (Testes de Interface Automatizados)
* **Versionamento:** Git/GitHub

## 🧪 Testes Automatizados
O projeto conta com uma suíte de testes de interface utilizando a biblioteca **Espresso**. 
Para rodar os testes:
1. Abra o projeto no Android Studio.
2. Navegue até `app/src/androidTest/java/com/example/myapplication/TaskListTest.java`.
3. Clique com o botão direito e selecione **Run 'TaskListTest'**.
